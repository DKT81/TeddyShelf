# TeddyShelf 0.4.1

Die Audioansicht bietet zusätzlich „TAF als Playlist (Originaldateien vollständig)“: jede Quelle wird vollständig als eigenes Kapitel in Listenreihenfolge übernommen. Die Abschnittslänge ist deaktiviert, Vorschau und Wellenform markieren die Dateigrenzen. Für TAF erfolgt weiterhin die nötige Audiokonvertierung, ohne die Quellen zu verändern.

Unter Einstellungen → Audio & Schnitt kann die Standard-Verarbeitung festgelegt werden. Bestehende gespeicherte Aufträge behalten ihr bisheriges Verhalten. Die beiden Zeitmodi bleiben verfügbar.

# Funktionsmatrix

| Bereich | Umsetzung |
|---|---|
| Sammlung B | Rekursive Ordnersuche, Serien-/Ordnergruppen, Coverkarten, Mehrfachauswahl, Suche und Statusfilter, Details unter der Bibliothek |
| Metadaten | Werkfelder, Spurentitel und Tracknummern, Folgen getrennt, Reihenfolge, Vorher-/Nachher-Vorschau, Stapeländerung, explizite Quell-Tags mit Sicherung |
| Namensprofile | Mehrere editierbare Profile, Standardauswahl, neue/löschbare Profile, Variablen, Live-Vorschau, ASCII/Pfadprüfung, JSON-Import/-Export |
| Cover verwalten | Ordner, eingebettetes Bild, manuelle Datei, Bildsuche, URL-Vorschlag, Rotation, Pixelzuschnitt, Zuordnung, Verwerfen, Entfernen |
| Cover-Vorgaben | Quellenreihenfolge, bestätigte Cover erhalten, leer/neutral, JPG/PNG, Kantenlänge, Seitenverhältnis, Vergrößern, Export-Tageinbettung |
| Cover-Manifest und Etiketten | JSON-Zuordnung mit Vorschau und eindeutigen IDs/Ordnern, lokale Bilder/URLs, A4-PDF mit wählbarer Etikettengröße |
| Audio | Mehrere geordnete Quellen, Vorhören, Seek, Wellenform, HH:mm:ss-Split und Rest, Namensvorschau, MP3/Opus/FLAC/WAV, TAF-Kapitel, lokal/Server/beides |
| Import | Gelesener Serverbestand und Zielvorschau, Kollisionsprüfung, eigenständige TAF-Konvertierung, vollständige lokale/Serverprüfung, keine RFID |
| Aufträge | Persistente Warteschlange, Zustände, Fortschritt, Protokoll, Export, Pause nach Titel, Fehler einzeln/gesamt wiederholen, unterbrochene fortsetzen, bestätigten Import erneut prüfen |
| Einstellungen | Verbindungstest, CA/TLS, Ordner, System/Hell/Dunkel, Startverhalten, Profile, Cover, Audio, Zeitlimits, Importregeln, Datenordner |
| Standalone | Portable EXE mit Python-, Qt- und Audio-Laufzeit; keine TonieToolbox-Installation |
| Spätere Bestandsverwaltung | Nur architektonisch berücksichtigt; wie vereinbart zurückgestellt |

Die Illustrationen der Entwürfe sind keine enthaltenen Originalcover. Funktionsgleiche Oberfläche, keine pixelgenaue Reproduktion der generierten Bilder. Bildsuche erfolgt im Browser; keine ungeprüfte automatische Cover-Erkennung. Sprache der Oberfläche: Deutsch.
